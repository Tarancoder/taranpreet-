# Day 21 – Support Vector Machine (SVM)

## 1. Objective

To understand the Support Vector Machine algorithm, its working principles, and its applications in supervised Machine Learning.

## 2. Introduction

Today I learned about Support Vector Machine (SVM), a supervised Machine Learning algorithm mainly used for classification and also for regression.

SVM works by finding the best decision boundary, called a hyperplane, that separates data points belonging to different classes. It tries to maximize the margin between the classes to improve the model's ability to make predictions on new data.

## 3. Topics Covered

### 3.1 Introduction to SVM

Support Vector Machine is used to classify data into different categories. It identifies an optimal hyperplane that separates the classes.

### 3.2 Hyperplane and Support Vectors

- **Hyperplane:** A decision boundary that separates different classes.
- **Support Vectors:** Data points closest to the hyperplane that help determine its position.
- **Margin:** The distance between the hyperplane and the nearest data points from each class.

SVM aims to find the hyperplane with the maximum possible margin.

### 3.3 Types of SVM

1. **Linear SVM:** Used when data can be separated using a straight line or linear decision boundary.
2. **Non-Linear SVM:** Used when data cannot be separated linearly. It uses kernel functions to handle more complex patterns.

### 3.4 Kernel Functions

Kernel functions help SVM handle non-linear data by representing relationships in a higher-dimensional feature space.

Common kernel functions include:
- Linear Kernel
- Polynomial Kernel
- Radial Basis Function (RBF) Kernel

### 3.5 Implementation Using Python

SVM can be implemented using the Scikit-learn library with the `SVC` class.

The model is trained using `fit()` and makes predictions using `predict()`. Feature scaling is generally important because SVM is sensitive to differences in feature ranges.
