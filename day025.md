## 2. Introduction

Today I completed the sample House Price Prediction project by applying the Machine Learning concepts learned during the training.

After performing EDA and preprocessing, I moved towards model development. The prepared dataset was used to train a regression model that could predict house prices based on the available property features.

## 3. Topics Covered

### 3.1 Dataset Preparation

Revisited the preprocessed dataset and ensured that the features and target variable were ready for model training.

### 3.2 Train-Test Split

Divided the dataset into training and testing sets.

- **Training Data:** Used to teach the model patterns from the dataset.
- **Testing Data:** Used to evaluate the model on unseen data.

### 3.3 Model Training

Applied a regression algorithm to learn the relationship between house features and their prices.

The model was trained using Scikit-learn with the `fit()` function.

### 3.4 Prediction

Used the trained model to predict house prices for the test data and understand how the model performs on unseen records.

### 3.5 Model Evaluation

Evaluated the model using regression evaluation metrics such as:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted prices.
- **Mean Squared Error (MSE):** Measures the average squared prediction error.
- **R² Score:** Indicates how well the model explains variations in house prices.

### 3.6 Project Completion

Combined the major stages of the project, including dataset loading, EDA, preprocessing, model training, prediction, and evaluation.
