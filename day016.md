# Introduction

Today I learned **Logistic Regression**, a supervised Machine Learning algorithm mainly used for classification problems.

Unlike Linear Regression, which predicts continuous numerical values, Logistic Regression predicts the probability of an observation belonging to a particular class.

The session focused on understanding the working principle of Logistic Regression, the Sigmoid function, classification thresholds, and its practical implementation using Python libraries such as Pandas, NumPy, Matplotlib, and Scikit-learn.

# Topics Covered

## 1. Introduction to Logistic Regression

Learned about Logistic Regression and its importance in classification problems.

Understood that it is used to:

- Predict categorical outcomes.
- Classify data into different categories.
- Estimate the probability of an event.
- Solve binary classification problems.

Examples include spam detection, disease prediction, and customer churn prediction.

## 2. Difference Between Linear and Logistic Regression

Studied the difference between Linear and Logistic Regression.

| Linear Regression | Logistic Regression |
|---|---|
| Used for regression problems | Used for classification problems |
| Predicts continuous values | Predicts class probabilities |
| Uses a straight-line equation | Uses the Sigmoid function |
| Output can be any numerical value | Binary classification probability ranges from 0 to 1 |

## 3. Sigmoid Function

Learned about the Sigmoid function, which converts the model's output into a probability between 0 and 1.

The mathematical formula is:

\[
\sigma(z)=\frac{1}{1+e^{-z}}
\]

Where:

- z = Linear combination of input features and model coefficients.
- e = Euler's number.
- σ(z) = Predicted probability.

Understood that the Sigmoid function produces an S-shaped curve.

## 4. Classification Threshold

Learned how predicted probabilities are converted into class labels using a classification threshold.

For a commonly used threshold of 0.5:

- Probability greater than or equal to 0.5 → Class 1.
- Probability less than 0.5 → Class 0.

Understood that changing the threshold can affect classification results.

## 5. Types of Logistic Regression

Studied different types of Logistic Regression:

- **Binary Logistic Regression:** Classifies data into two categories, such as Yes/No or 0/1.
- **Multinomial Logistic Regression:** Classifies data into three or more categories without a natural order.
- **Ordinal Logistic Regression:** Used when categories have a meaningful order.

## 6. Implementation Using Python

Learned how to implement Logistic Regression using Scikit-learn.

Used:

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()

model.fit(X_train, y_train)

y_pred = model.predict(X_test)
```

Understood the basic steps involved in training a classification model and generating predictions.

## 7. Model Evaluation

Learned about different evaluation metrics used to measure classification performance.

- Accuracy: Measures the proportion of correct predictions.
- Precision: Measures how many predicted positive cases are actually positive.
- Recall: Measures how many actual positive cases are correctly identified.
- F1-Score: Represents the balance between precision and recall.
- Confusion Matrix: Shows correct and incorrect classification predictions.

Understood why accuracy alone may not always be sufficient for evaluating a classification model.
