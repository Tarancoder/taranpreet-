# Introduction

Today I learned **Polynomial Regression**, a supervised Machine Learning algorithm used to predict continuous numerical values when the relationship between input and output variables is non-linear.

Unlike Simple Linear Regression, which fits a straight line to the data, Polynomial Regression fits a curved line by introducing polynomial features.

The session focused on understanding the mathematical equation, the role of polynomial degree, and the practical implementation of Polynomial Regression using Python libraries such as NumPy, Pandas, Matplotlib, and Scikit-learn.

---

# Topics Covered

## 1. Introduction to Polynomial Regression

Learned about Polynomial Regression and how it is used to model non-linear relationships between variables.

Understood that it is useful when a straight line cannot properly represent the relationship between input and output data.

## 2. Mathematical Equation

Learned the general mathematical equation of Polynomial Regression:

\[
y = b_0+b_1x+b_2x^2+\cdots+b_nx^n
\]

Where:

- y = Predicted output.
- x = Independent variable.
- b₀ = Intercept.
- b₁, b₂, ... = Coefficients.
- n = Degree of the polynomial.

Understood that increasing the polynomial degree allows the model to fit more complex curves.

## 3. Difference Between Linear and Polynomial Regression

Studied the difference between Linear and Polynomial Regression.

- Linear Regression fits a straight line.
- Polynomial Regression fits a curved relationship when required.
- Linear Regression is suitable for approximately linear relationships.
- Polynomial Regression is useful for non-linear patterns.

## 4. Understanding Polynomial Degree

Learned about polynomial degree and its effect on the regression curve.

- Degree 1: Represents a straight-line relationship.
- Degree 2: Represents a quadratic curve.
- Degree 3: Represents a cubic curve.
- Higher degrees: Allow more complex curves.

Also understood that choosing a very high degree may lead to overfitting.

## 5. Implementation Using Python

Learned how to implement Polynomial Regression using Scikit-learn.

Used:

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

poly = PolynomialFeatures(degree=2)

X_poly = poly.fit_transform(X)

model = LinearRegression()
model.fit(X_poly, y)
```

Understood that PolynomialFeatures transforms the original input features into polynomial features before training the Linear Regression model.

## 6. Visualization of Polynomial Regression

Learned how to visualize Polynomial Regression using Matplotlib.

Created scatter plots to represent actual data points and plotted the polynomial regression curve to understand how the model fits non-linear data.
