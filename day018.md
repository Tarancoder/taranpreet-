# Day 18 – Decision Trees and Random Forests

## 1. Objective

To understand Decision Tree and Random Forest algorithms, their working principles, and their applications in Machine Learning for classification and regression problems.

## 2. Introduction

Today I learned about two important supervised Machine Learning algorithms: Decision Trees and Random Forests. Both algorithms can be used for classification and regression tasks.

A Decision Tree makes predictions by dividing data into smaller groups based on different conditions. Random Forest improves this approach by combining multiple decision trees to produce more reliable predictions.

## 3. Topics Covered

### 3.1 Decision Tree

A Decision Tree is a supervised learning algorithm that makes decisions using a tree-like structure. It divides the dataset based on feature values until it reaches a final prediction.

Its main components are:
- **Root Node:** Represents the starting point of the tree.
- **Decision Nodes:** Represent conditions or questions about the data.
- **Branches:** Represent the possible outcomes of a condition.
- **Leaf Nodes:** Represent the final prediction.

### 3.2 Working of Decision Tree

The algorithm selects the best feature to split the dataset at each step. It continues dividing the data into smaller groups until a stopping condition is reached.

Some important splitting techniques are:
- **Gini Impurity:** Measures how mixed the classes are in a group.
- **Entropy:** Measures the impurity or uncertainty in the dataset.
- **Information Gain:** Measures the reduction in entropy after a split.

### 3.3 Random Forest

Random Forest is an ensemble learning algorithm that combines multiple Decision Trees to improve prediction accuracy and reduce overfitting.

It works by:
- Creating multiple random samples from the training dataset.
- Training a separate Decision Tree on each sample.
- Combining the predictions of all trees.
- Using majority voting for classification and averaging for regression.

### 3.4 Decision Tree vs Random Forest

| Decision Tree | Random Forest |
|---|---|
| Uses a single tree | Uses multiple trees |
| Easy to understand and visualize | More complex to interpret |
| Can easily overfit | Generally reduces overfitting |
| Usually faster to train | May require more training time |

### 3.5 Implementation Using Python

Both algorithms can be implemented using the `scikit-learn` library.

Important classes:
- `DecisionTreeClassifier`
- `DecisionTreeRegressor`
- `RandomForestClassifier`
- `RandomForestRegressor`

The models can be trained using `fit()` and used for predictions with `predict()`.
