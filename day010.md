# Introduction

Today I learned **Matplotlib**, one of the most popular Python libraries used for data visualization. In Data Science and Machine Learning, visualizing data helps us understand patterns, trends, relationships, and distributions before building models.

The session started with installing Matplotlib and then creating different types of charts using sample datasets. I also learned when each graph should be used and how different graphs help in analyzing data.

Used:


## 2. Introduction to Data Visualization

Discussed the importance of data visualization in Data Science.

Learned that graphs help to:

- Understand datasets easily.
- Identify trends and patterns.
- Compare different values.
- Detect outliers.
- Find relationships between variables.
- Present results in a clear and attractive way.

Learned that a line graph is useful for showing:

- Continuous data
- Growth over time
- Trends
- Changes between values

- Title
- X-axis label
- Y-axis label

## 4. Bar Plot

Created bar charts to compare different categories.

Learned that bar plots are useful for:

- Comparing values
- Displaying categorical data
- Comparing sales, marks, population, etc.

Observed the difference between vertical and horizontal bars.

---

## 5. Scatter Plot

Created scatter plots using two numerical variables.

Learned that scatter plots help to:

- Show relationships between variables.
- Identify positive or negative relationships.
- Detect clusters.
- Find unusual data points (outliers).

Discussed how scatter plots are useful before building Machine Learning models.

---

## 6. Histogram

Generated histograms to understand data distribution.

Learned that histograms help in:

- Finding frequency distribution.
- Understanding how data is spread.
- Identifying skewness.
- Detecting unusual values.

Observed how changing the number of bins affects the graph.

---

## 7. Box Plot

Created box plots to study the spread of data.

Learned that box plots display:

- Minimum value
- Maximum value
- Median
- First Quartile (Q1)
- Third Quartile (Q3)
- Outliers

Discussed why box plots are commonly used during data cleaning.

---

## 8. Correlation Heatmap

Learned about correlation between numerical variables.

Created a correlation matrix and displayed it as a heatmap.

Discussed:

- Positive correlation
- Negative correlation
- No correlation

Learned that correlation heatmaps help identify which features are strongly related and are useful during feature selection in Machine Learning.

---

## 9. Understanding Different Types of Graphs

Compared different visualization techniques.

| Graph | Main Purpose |
|--------|--------------|
| Line Plot | Show trends over time |
| Bar Plot | Compare different categories |
| Scatter Plot | Show relationship between two variables |
| Histogram | Show frequency distribution |
| Box Plot | Detect spread and outliers |
| Correlation Heatmap | Show relationships between numerical features |
