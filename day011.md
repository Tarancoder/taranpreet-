Today I learned **Exploratory Data Analysis (EDA)** using the Titanic dataset. EDA is an important step in Data Science and Machine Learning that helps us understand a dataset before applying any Machine Learning algorithms.

The Titanic dataset contains information about passengers who travelled on the Titanic, including their age, gender, passenger class, ticket fare, cabin details, and survival status.

# Topics Covered

## 1. Introduction to the Titanic Dataset

Learned about the Titanic dataset and its different features.

Important columns included:

- PassengerId – Unique identification number of each passenger.
- Survived – Indicates whether the passenger survived (1) or did not survive (0).
- Pclass – Passenger class (1st, 2nd, or 3rd).
- Name – Name of the passenger.
- Sex – Gender of the passenger.
- Age – Age of the passenger.
- SibSp – Number of siblings or spouses aboard.
- Parch – Number of parents or children aboard.
- Ticket – Ticket number.
- Fare – Ticket fare paid by the passenger.
- Cabin – Cabin number.
- Embarked – Port where the passenger boarded.

## 2. Loading and Exploring the Dataset

Loaded the Titanic dataset using Pandas.

```python
import pandas as pd
import numpy as np

df = pd.read_csv("titanic.csv")
```

Explored the dataset using:

- `df.head()` – Displays the first five rows.
- `df.shape` – Displays the number of rows and columns.
- `df.info()` – Provides information about data types and non-null values.
- `df.describe()` – Displays statistical summaries.
- `df.columns` – Displays column names.

## 3. Understanding Data Types

Identified numerical and categorical features in the Titanic dataset.

- Numerical Features: Age, Fare, SibSp, Parch.
- Categorical Features: Sex, Embarked, Pclass, Survived.

Understood the importance of identifying data types before performing analysis.

## 4. Handling Missing Values

Checked the dataset for missing values using:

```python
df.isnull().sum()
```

Observed that columns such as Age, Cabin, and Embarked contained missing values.

Learned different methods to handle missing data:

- Filling missing Age values using the median.
- Filling missing Embarked values using the mode.
- Understanding why columns with a large number of missing values may require special treatment.

## 8. Multivariate Analysis

## 9. Outlier Detection

Learned how to identify outliers in numerical columns such as Age and Fare.

Used box plots and the Interquartile Range (IQR) method to understand unusual values.

## 10. Correlation Analysis

Calculated the correlation between numerical features to understand their relationships.

Learned how correlation helps identify features that are related to each other and supports further feature analysis before Machine Learning model development.
