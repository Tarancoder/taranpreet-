# Introduction

Today I learned **Linear Regression**, one of the fundamental supervised Machine Learning algorithms used for predicting continuous numerical values.

Linear Regression is used to establish a relationship between input variables and an output variable by fitting a straight line through the given data points.

The session focused on understanding the working principle of Linear Regression, its mathematical equation, different types, and its practical implementation using Python libraries such as Pandas, NumPy, Matplotlib, and Scikit-learn.

I also learned how Linear Regression can be used to make predictions based on existing data.

# Topics Covered

## 1. Introduction to Machine Learning

Revised the concept of Machine Learning and learned about supervised learning.

Understood that Linear Regression is a supervised learning algorithm because it learns from labelled training data.

Learned that supervised learning involves:

- Input Features: Variables used to make predictions.
- Target Variable: The output that the model tries to predict.
- Training Data: Data used to train the model.

## 2. Introduction to Linear Regression

Learned about Linear Regression and its importance in predictive analysis.

Understood that it is used to:

- Predict continuous numerical values.
- Identify relationships between variables.
- Analyze trends in datasets.
- Estimate future values based on existing data.

Examples include predicting house prices, salaries, sales, and student marks.

## 3. Mathematical Equation of Linear Regression

Learned the basic mathematical equation of Linear Regression:

\[
y = mx + c
\]

Where:

- y = Predicted output.
- x = Input variable.
- m = Slope of the line.
- c = Intercept.

Understood that the slope determines how much the output changes when the input increases by one unit, while the intercept represents the predicted output when the input is zero.

## 4. Types of Linear Regression

Studied two main types of Linear Regression.

**Simple Linear Regression:**

Uses one independent variable to predict one dependent variable.

Example: Predicting salary based on years of experience.

**Multiple Linear Regression:**

Uses two or more independent variables to predict a dependent variable.

Example: Predicting house prices based on area, number of bedrooms, and location-related features.

## 5. Best Fit Line

Learned about the best fit line and how Linear Regression finds a line that represents the relationship between input and output variables.

Understood that the model tries to minimize the difference between actual values and predicted values.

Studied the concept of residuals, which represent the difference between actual and predicted values.

## 6. Implementation Using Python

Learned how to implement Linear Regression using the Scikit-learn library.

Used:

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
```

Understood the basic steps involved in implementation:

- Loading the dataset.
- Selecting input and output variables.
- Splitting the dataset into training and testing sets.
- Training the model using `fit()`.
- Making predictions using `predict()`.

## 7. Model Evaluation

Learned about different evaluation metrics used to measure the performance of a Linear Regression model.

Studied:

- Mean Absolute Error (MAE): Measures the average absolute difference between actual and predicted values.
- Mean Squared Error (MSE): Measures the average squared difference between actual and predicted values.
- Root Mean Squared Error (RMSE): Represents the square root of MSE.
- R-squared (R²): Measures how well the model explains the variation in the target variable.

Understood that evaluation metrics help determine how accurately a model makes predictions.

## 8. Visualization of Linear Regression

Learned how to visualize the relationship between input and output variables using Matplotlib.

Created scatter plots to display actual data points and plotted the regression line to understand how well the model fits the data.

Understood how visualization helps in interpreting model predictions and identifying patterns.
