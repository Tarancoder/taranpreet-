# Topics Covered

## 1. Introduction to Regularization

Learned about regularization and its importance in Machine Learning.

Understood that regularization helps to:

- Reduce overfitting.
- Control model complexity.
- Improve generalization.
- Prevent the model from becoming too sensitive to training data.

Regularization works by adding a penalty term to the model's loss function.

## 2. Overfitting and Regularization

Learned about overfitting and how it affects Machine Learning models.

Overfitting occurs when a model learns the training data too closely, including noise and unnecessary patterns, resulting in poor performance on unseen data.

Understood that regularization helps control overfitting by penalizing large model coefficients.

## 3. Ridge Regression (L2 Regularization)

Learned about Ridge Regression, also known as L2 Regularization.

Ridge Regression adds a penalty based on the square of the model coefficients.

Key points:

- Reduces the magnitude of coefficients.
- Helps control model complexity.
- Usually does not make coefficients exactly zero.
- Useful when multiple features contribute to the prediction.

## 4. Lasso Regression (L1 Regularization)

Learned about Lasso Regression, also known as L1 Regularization.

Lasso Regression adds a penalty based on the absolute values of the model coefficients.

Key points:

- Reduces the magnitude of coefficients.
- Can make some coefficients exactly zero.
- Helps in automatic feature selection.
- Useful when some features are less important.

## 5. Difference Between Ridge and Lasso Regression

Understood the differences between the two regularization techniques.

| Ridge Regression | Lasso Regression |
|---|---|
| Uses L2 regularization | Uses L1 regularization |
| Penalizes squared coefficients | Penalizes absolute coefficients |
| Shrinks coefficients | Can shrink coefficients to zero |
| Generally retains all features | Can perform feature selection |
| Gentle regularization | Can be more restrictive |

## 6. Regularization Parameter (Alpha)

Learned about the alpha parameter, which controls the strength of regularization.

- Low Alpha: Applies a smaller penalty.
- High Alpha: Applies a stronger penalty.
- Very high Alpha: May lead to underfitting.

Understood that selecting an appropriate alpha value is important for achieving good model performance.

## 7. Implementation Using Python

Learned how to implement Linear, Ridge, and Lasso Regression using Scikit-learn.

Used:

```python
from sklearn.linear_model import LinearRegression, Ridge, Lasso
```

Understood how to create models, train them using `fit()`, and generate predictions using `predict()`.

Also learned how to evaluate models using Mean Absolute Error (MAE) and R-squared (R²).
