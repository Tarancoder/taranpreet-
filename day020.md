## 3. Topics Covered

### 3.1 K-Means Clustering

K-Means is an unsupervised learning algorithm that divides a dataset into K different clusters.

Each cluster has a centroid, which represents the center of that cluster. Data points are assigned to the nearest centroid.

### 3.2 Working of K-Means Algorithm

The algorithm follows these steps:

1. Select the number of clusters (K).
2. Initialize the cluster centroids.
3. Calculate the distance between data points and centroids.
4. Assign each data point to its nearest centroid.
5. Update the centroids based on the assigned data points.
6. Repeat the process until the clusters become stable.

### 3.3 Elbow Method

The Elbow Method helps determine the appropriate number of clusters for K-Means.

It uses the Within-Cluster Sum of Squares (WCSS), which measures the variation within each cluster. A graph is plotted between the number of clusters and WCSS.

The point where the decrease in WCSS starts slowing down is called the elbow point. It helps identify a suitable value of K.

### 3.4 Feature Scaling in Clustering

Feature scaling is important in clustering because distance-based algorithms such as K-Means can be affected by differences in feature ranges.

Common scaling techniques include:
- **Standardization:** Transforms data using its mean and standard deviation.
- **Normalization:** Scales values to a specified range, commonly 0 to 1.

### 3.5 Visualization of Clusters

Clusters can be visualized using scatter plots. Different colors can represent different clusters, making it easier to understand how data points are grouped.
