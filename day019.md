## 3. Topics Covered

### 3.1 Loading Datasets

A dataset can be loaded into Python using libraries such as Pandas and NumPy. Pandas provides functions to read data from different file formats.

Some commonly used functions are:

- `pd.read_csv()` – Loads a CSV file.
- `pd.read_excel()` – Loads an Excel file.
- `head()` – Displays the first five rows.
- `tail()` – Displays the last five rows.
- `info()` – Provides information about columns and data types.
- `describe()` – Displays statistical information about numerical columns.
- `shape` – Returns the number of rows and columns.

### 3.2 Introduction to Clustering

Clustering is an unsupervised Machine Learning technique that groups similar data points together.

The main objective is to:
- Group similar data points into clusters.
- Identify patterns and relationships in data.
- Discover hidden structures without using predefined labels.

### 3.3 Types of Clustering

Some common clustering techniques are:

1. **K-Means Clustering:** Divides data into a predefined number of clusters based on similarity and distance from cluster centers.
2. **Hierarchical Clustering:** Creates a hierarchy of clusters by repeatedly merging or splitting groups.
3. **DBSCAN:** Groups data points based on their density and identifies outliers or noise.

### 3.4 K-Means Clustering

K-Means is one of the most commonly used clustering algorithms.

Its basic steps are:

1. Select the number of clusters (K).
2. Initialize K cluster centroids.
3. Assign each data point to its nearest centroid.
4. Calculate new centroids based on the assigned points.
5. Repeat the process until the clusters become stable.

### 3.5 Evaluation of Clustering

Clustering results can be evaluated using different techniques.

- **Elbow Method:** Helps determine a suitable number of clusters.
- **Silhouette Score:** Measures how well data points fit within their assigned clusters.
