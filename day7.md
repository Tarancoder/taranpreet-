## 9. Precision and Recall (Introduction)

Introduced two important Machine Learning evaluation metrics:

### Precision

Understood the formula:

Precision = TP / (TP + FP)

Where:

- TP → True Positives
- FP → False Positives

---

### Recall

Studied the formula:

Recall = TP / (TP + FN)

Where:

- FN → False Negatives

Discussed how these metrics are used to evaluate classification models in machine learning.

Implemented the basic function structure for calculating Precision and Recall.
